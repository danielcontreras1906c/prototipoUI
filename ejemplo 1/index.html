Proyecto académico

Un ejemplo para probar y dibujar

Esta maqueta explora cómo consultar cambios de recolección, lugares de entrega y preparación de residuos en Carrillo.

Los horarios, avisos, campañas, puntos y posiciones del esquema son ficticios. No utilicés estos datos para sacar o trasladar residuos. Las condiciones reales deben verificarse con la Municipalidad o el receptor.

La arquitectura es una propuesta inicial: todavía debe contrastarse con el card sorting y las pruebas con participantes reales. Esta maqueta no acredita que esas actividades ya se hayan realizado.

No se envían consultas, no se solicitan datos personales ni se activan notificaciones. La comunidad seleccionada se mantiene únicamente mientras navegás esta página.
